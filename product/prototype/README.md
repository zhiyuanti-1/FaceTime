# 页面骨架索引

当前以[需求](../需求.md) §2 为准。旧 PNG、生成器和 IA v2 HTML 已随 CR-1.0-037 清理，Git 历史可追溯。

页面入口位于 apps/web/src/pages，布局位于 apps/web/src/app。10 个业务页面加登录、未找到两页。项目详情的简历与岗位标签显示真实数据，Gap 诊断、叙事定制、题目预览为后续入口。

面试页采用专注布局，其余业务页使用顶部导航。工作台采用 Figma 的折光问候区、四张指标卡、最近项目与快捷操作。项目数和最近项目使用真实接口，其他指标及历史报告明确显示待接入。新建项目浮层按已确认需求加入简历选择和 JD，删除在项目详情中进行两次确认。

简历库 `/resumes` 采用 Figma 画板的折光标题、纵向简历列表和分区详情。搜索在列表页进行，新建、详情和导入从右侧以抽屉打开。桌面可拖动左侧箭头调整宽度至全屏，窄屏直接全宽展示。全站前端视觉规范见[技术约束 §12.9](../../docs/技术约束.md#129-折光卡片-ui-规则)。
