## 目标、场景与核心流程

求职者按岗位与简历模拟面试，通过专业且有边界的追问、可解释扣分和改进建议练习。不得将简历疑点等同于造假。

设置模式与岗位权重 → PDF/图片/文本简历 → 提取/结构化 → 用户修正确认 → 组卷 → 文字/录音 → 转写确认 → 规则+AI 评分 → 最多两层追问 → 报告、JSON/打印导出。

常规模式默认 5 八股+5 简历题，追问另记；专项训练只出知识题。本轮重新盘点：已有10池各20题，共200题，index标为1.0.0-seed。PM-06 v1.2 的实际池为 js/vue/react/html/network/algorithm/database/os/java/engineering，ts/behavioral 暂缺；seed允许未人工审核但必须警告，curated才要求审核。旧开头仍保留12池及700题最低集，列为冲突，不作为当前定案。权重数值由配置提供，示例不是固定业务规则。

## 依赖和技术风险

| 依赖/风险 | 缓解与边界 |
|---|---|
| 百度 ASR | 格式、时长、时间戳、置信度待实测；缺能力禁用相应规则；可文字输入 |
| 百度 OCR | 质量低转手填；上传必须告知第三方处理 |
| DeepSeek | JSON 不等于契约正确；校验结构、证据、量纲、预算；失败用可用规则项与模板 |
| 本地 OCR/ASR/LLM | 2.0 评估中文样本、许可证、权重、硬件与成本后启用 |
| 动作识别 | 2.0；连续帧、遮挡、设备异常、镜头抖动保护，防误判 |
| 密钥/CORS | 本地代理优先；direct 凭证可被浏览器读取且跨域未验证 |
| 限流/成本 | 队列、取消、退避与 token/请求预算；不承诺免费额度可用 |
| 隐私 | 本地持久化不等于不上传；数据最小化、留存、删除与供应商说明必须区分 |
