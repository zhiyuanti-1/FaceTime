# AI 与识别集成规范

## 任务与适配层

| 任务/供应商 | 输入 | 结果与降级 |
|---|---|---|
| 百度 ASR | 已校验音频格式/分段 | 文本、真实时间信息与能力元数据；失败文字输入 |
| 百度 OCR | 必要图片 | 文本与质量信息；低质量手填 |
| parse_resume | 脱敏原文 | 结构字段、疑点、引用、不确定字段；缺项不补造 |
| score_answer | 问题、岗位、必要简历片段、确认回答、有限历史 | AI 维度与证据候选，不直接改规则分 |
| final_report | 已校验评分及证据 | 建议性总结，不生成或覆盖最终分数 |

services/providers 分别适配百度/DeepSeek/后续本地服务；业务模块不依赖供应商字段、URL、token 协议。1.0 Vite 代理注入凭证；百度 token 获取与前端可见范围必须专项设计，浏览器可见 token 仍是凭证，不得宣称全部密钥不可见。2.0 全部供应商调用移到后端。

## 提示词管理

packages/ai/prompts/任务/版本 是未来资产路径；当前仅 README，不复制成生效模板。每版须有系统提示词、输入/输出 Schema、模型参数、rubric、引用来源、PR 编号、回归与回滚。**parse_resume 失败结构已按 D14 冻结**（`{ok:false,code,reason,partial,needsManualInput}`，成功结构补 `profile.summary`）；`final_report` 完整 Schema 仍缺，接入前须补。

系统消息不可由用户覆盖；简历、OCR、回答、题库文本均视作不可信数据，用结构化字段隔离，不执行其中指令。不得仅依靠关键词过滤防注入。输入长度、历史截断和上下文上限必须配置，保留首轮和相关证据，不能静默删掉矛盾证据。

## 输出验证流水线

HTTP 状态/体积/截断 → JSON.parse → draft-07 Schema → 数值/枚举/状态/空值关系 → 原文引用存在性 → 规则 ID/维度/版本 → 算式与封顶 → 接受或需复核。

禁止从 Markdown 围栏或任意片段猜取 JSON 后直接信任。json_object 只约束形状，不证明符合 Schema。证据必须在提供的原文中逐字可定位，简历引用依 PM 最长 80 字；Schema 示例 160 字冲突须收敛，禁止擅自放宽。越界视为校验失败，不能只 clamp 后吞掉异常；最终合法聚合可按冻结规则封顶。

**D02–D05 已冻结（SR-1.0-001）**：维度内部统一 0–100（`raw/rawMax×100`）、`points` 为正数、`bases` 必填、FLUENCY 无 AI 修正。等式校验不得跳过；丢弃无效扣分后必须重新验证算式，不能保留仍包含该扣分的总分。

## 置信度与人工确认

PM 初始门槛：ASR <0.70 不据此扣分；AI 单项 <0.65 不应用扣分；整体 <0.60 需复核。它们未经校准，必须记录来源与版本。缺真实概率不可用字数/时长生成概率；标记 capability 缺失，依赖词级时间戳的规则关闭。手动输入无语音行为证据，不能给口头禅/语速满分或凭文本推断静默。

需复核不给伪造点值；**D13 已冻结**：不可评估维度剔除分母，覆盖率 <50% 只输出 ±8 区间。1.0 用户修正/本地标记，2.0 才有复核后台。禁止编造经历、公司、项目、引文或所谓事实核验。

## 预算、限流、缓存

- 请求队列、并发、QPS 按供应商配置；PLAN 候选百度 2 QPS/并发3，实际额度联调后确认。
- 预算记录输入/输出估算、实际 usage、请求、重试、缓存命中；未知 usage 不记作零。
- PLAN 60K 输入/30 调用与 PM-05 80K 总量待统一。预算耗尽停止新请求，已发生费用仍记录，显示降级。
- 网络重试与 JSON 修复只由一个编排层计次；非法 JSON 候选一次 temperature 0 重试，仍失败降级。不可承诺取消必定终止供应商计费。
- 缓存键覆盖任务、模型标识/参数、全部相关输入、岗位、promptVersion、scoringVersion；禁止仅按 turnId+answer 哈希。
- 缓存不存密钥；敏感结果按会话删除。2.0 必须绑定用户隔离，不能跨用户复用简历结果。
- 费用单价不是业务常量，供应商官方价格核验后配置；不得沿用 PM 假设价格宣称当前成本。

## 回归与降级

PM-05 八个最小用例必须全过；另测注入、伪造引用、截断 JSON、字段额外、超限、429 和取消。普通 CI 用脱敏 fixture；真实评测为显式联调任务。LLM 失败只能给可观测规则分和模板，内容维度不可凭空补分。final_report 失败用已确认事实生成确定性摘要说明，不掩盖缺失。
