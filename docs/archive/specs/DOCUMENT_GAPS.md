## 冻结流程与待确认

原文定位 → 八面影响评估 → 改前改后 → PM/技术及需求方按职责确认 → CR/SR/PR → 同步 PM 原文、Schema 与用例 → 标记冻结。只改本台账不等于批准业务规则。

本轮无阻塞结构初始化的问题。后续编码前优先确认三组：评分量纲/算式/状态；组卷算例/空简历/无解行为；第三方上传/告知/direct 临时凭证边界。其余以命中模块为准冻结，不用提问阻断独立工作。
