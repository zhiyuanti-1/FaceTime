# 安全、密钥与隐私规范

本文件是技术要求，不代替法律结论。**D01 已于 2026-11-03 冻结**：允许表述「数据保存在本机浏览器」，但必须同时说明简历文本与录音会上传第三方识别服务；禁止单独用「数据不出浏览器/本机」作为对外承诺。

## 密钥与本地边界

- 禁止密钥/Token/API Key 进入源码、VITE_*、define 注入、静态文件、日志、fixture、截图、导出和提交。
- 本地秘密仅 Vite 进程从未提交环境文件读取；未来必须添加忽略规则和无值 env 示例。本轮不创建运行配置。
- 非 VITE_ 前缀也不是自动安全：禁止把整个 process.env 注入客户端。
- 本地代理只绑定回环地址，固定上游白名单；禁止开放 URL 转发，校验来源、请求大小，错误响应不回显凭证。
- dist 不具备代理能力；vite preview 不是生产服务器。局域网分享/公网使用必须重新评审并改服务端托管。
- direct 为本地风险备用：仅用户显式另供临时凭证；绝不从代理自动取密钥。1.5s 只能表示探测/状态变化，不承诺凭证与 CORS 未满足时连通。
- direct 凭证浏览器可读，内存优先；若沿用 PM sessionStorage 必须风险提示、不持久化到 IndexedDB、不进入导出，并在会话结束清理。
- 百度 access_token 若进入浏览器，也按凭证处理。密钥泄漏立即吊销、轮换、审计和停止受影响入口。

## 数据流与最小化

| 数据 | 1.0 保存/处理 | 第三方/未来边界 |
|---|---|---|
| 简历原文/结构 | 本地 IndexedDB，用户可清理 | OCR/LLM 仅必要内容，先脱敏与告知 |
| 录音 | 本地独立 Blob，PLAN 默认7天候选 | ASR 发送必要片段；不传给无关模型 |
| 回答/引用 | 本地会话/报告 | LLM 只给相关上下文，避免全文简历 |
| 姓名/电话/身份证/地址 | 非评分必需，优先移除 | 不作为岗位能力依据 |
| 诊断日志 | 本地500条环形候选 | 无第三方埋点，禁止正文/音频/凭证 |
| 人脸/姿态 | 1.0 不采集 | 2.0 单独告知，优先事件/关键点最小化 |

告知必须说明供应商、数据类型、目的、网络传输和可选离线/手填路线，不用代理转发掩盖第三方处理。第三方留存不能等同本地删除，需明确能力与限制。留存矩阵待确认，不扩写 PM 未给期限。

## 文件与展示

限制文件体积、页数、解压/解析资源；扩展名/MIME/内容联合校验。PDF/图片只当数据，禁止执行嵌入脚本；原文默认转义输出，禁止直接 innerHTML。提示词注入按不可信数据处理，不能只靠关键词。远程 URL 导入需单独 SSRF 设计，当前不提供。

## 删除与备份

删除会话覆盖会话、独立音频、报告、相关缓存/索引；简历可能被多会话引用，删除/保留语义须明确。全量清除包含所有本地 store、activeSession、recentQuestions 和临时凭证，不能只清 UI。时间清理不能代替用户删除。

2.0 按 PM 删除后24h物理清除目标设计数据库、对象、派生结果和任务；备份/第三方删除限制必须单列，在恢复后重放删除记录。不能在备份无法满足时宣称完全清除。1.0 迁移备份也受同一删除要求约束。

## 后端与公网预留

2.0 服务端鉴权、资源归属、角色最小权限、配额与审计；前端隐藏按钮不算授权。JWT/cookie/刷新令牌方案在后端 ADR 冻结，cookie 使用时评估 CSRF。3.0 TLS、Secret/KMS、密钥轮换、数据库网络隔离、依赖扫描、备份恢复、告警与事件响应。错误监控上传前清洗 URL、请求体、用户内容和鉴权头。
