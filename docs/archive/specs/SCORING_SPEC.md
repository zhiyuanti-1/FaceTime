# 评分规则架构规范

业务事实源：[PM-04](../pm/04-评分原则与规则表.md)。本文件不实现算法、不新增阈值。PM 阈值为待校准初值，不能声称科学结论。**D02–D05、D13 已于 2026-11-03 冻结（SR-1.0-001），可实现；D08 仍未决**，涉及 ASR 推导置信度参与扣分的实现须等冻结。

## 双引擎与职责

packages/shared/scoring 负责纯规则计算边界；packages/rules/scoring 保存版本化配置；features/scoring 编排规则、AI 校验和聚合。AI 负责内容理解类候选，规则负责可观测行为；AI 不得覆写规则，不能给 filler/body 分。**FLUENCY 的 AI 辅助修正已取消（D05 冻结），该维度纯规则输出，AI 不参与。**

| 维度 | PM 1.0 原始权重 | 来源 |
|---|---|---|
| CONTENT | 40 | AI |
| FLUENCY | 15 | 规则主、AI 辅 |
| FILLER | 10 | 规则 |
| BODY | 0 | 未启用 |
| RESUME | 15 | AI 主+规则 |
| FIT | 10 | AI |

完整可评估时 1.0 权重和 90，依 PM 归一化；BODY score=null/status=NOT_ENABLED，不显示 0。**D13 已冻结**：缺维度与全不可评估一律剔除分母并重新归一化，覆盖率 <50% 只输出 ±8 区间、不给点值；禁止按零或满分处理。岗位题库权重与评分维度权重为两套不同配置。

## 规则表结构要求

| 字段 | 约束 |
|---|---|
| ruleId/dimension/scoringVersion | 稳定 ID、所属维度、语义版本 |
| enabled/applicableVersions | 启用与版本范围 |
| requiredCapabilities | 词级时间戳、真实置信度、VAD、姿态等前置 |
| thresholds/window/dedupWindowMs | 有单位、窗口边界、去重参数 |
| points/cap/exclusiveGroup | 分值、封顶、互斥档位；**points 为正数**（D03 冻结），方向由所属集合决定，封顶顺序「单条→单维 50%→100」 |
| evidenceRequirements/confidencePolicy | 来源、原文、时间、阈值和可评估要求 |
| source/status | PM 来源、草案/校准/冻结 |

配置必须 Schema 校验、不可变快照、显式版本。算法不得内嵌阈值；不存在有效配置时拒绝相关评分，不悄悄使用默认值。

## 防误判与解释

- 先判断可评估性，再判断触发。网络、设备、识别失败和低置信度记 INCONCLUSIVE，不扣分。
- 任何扣分必须含 ruleId、dimension、points、实际值、阈值、单位、证据、时间、置信度来源与 status。没有词级信息不得伪造词位置。
- 同事件去重，密度高低档互斥取高档；加分同证据不重复，RES-003 与 BON-003 防双计。
- BODY 2.0 需真实连续帧、采样与可评估性；遮挡、镜头抖动、权限拒绝不算用户行为。
- 不评外貌、年龄、性别、婚育、口音、方言、残障或学历出身；违规为 P0 规则缺陷。
- AI 未提供可验证 base 或等式不成立，需复核；不得为算式成立反推假 base。
- 单条、单维、全场封顶与舍入顺序必须统一，禁止按题重复应用全场 cap。

## 历史与复核

报告保存 scoringVersion/promptVersion/bankVersion/model、输入摘要哈希、规则事件与分数快照。历史口径不静默重算；跨口径对比提示差异。复核保存原记录、判定、理由、操作者和修订版本，明确展示修订。1.0 只有用户修正与本地标记，2.0 才建设复核队列，3.0 按 PM 定义 SLA。

## 验收门槛

按 PM-04：≥20 场人工标注，1.0 Spearman≥0.60，维度 MAE≤12；抽检200事件误报≤10%、漏报≤20%；规则重复完全一致，AI 波动≤5。门槛未达只能标内测，不能称评分可用。样本与证据尚缺，本轮不验收评分质量。
